# AI Code Review Assistant
AI-powered platform that analyzes source code and provides
automated code reviews, quality insights, and improvement suggestions.

Features
- AI-powered code analysis
- Static code analysis
- Code quality findings
- JWT authentication
- Project management
- Review history

## Tech Stack
Python | JavaScript | Node.js | PostgreSQL | AI

## Architecture
Frontend → Backend API → AI/Static Analysis → Database
